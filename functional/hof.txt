Higher-Order Function (HOF) is a function that either:

1. Takes another function as an argument, or
2. Returns a function as its output.

Used to make code more flexible, reusable, and dynamic.

# Lambda 
 Lambda argument : expression

# Compound Function
A Compound function is a function in which the output of one function becomes the input of another function ==> f(g(x))

# Callback Function
A callback function is a function that you pass as an argument to another function, so that it can be called (executed) later, usually after some action is completed

#Recursive function
A Recursive is a function that calls itself in order to solve a smaller version of that problem
